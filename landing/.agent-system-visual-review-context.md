## Objective
Fix scroll snap functionality, remove blur/electric gradient from HowItWorks, and use i18n for demo label in HeroPreview.

## Baseline (Before)
- **Scroll Snap**: CSS had `scroll-snap-type: y proximity` on `html` but no snap alignment on sections
- **HowItWorks**: Contained `blur-[100px]` halo div and `bg-[linear-gradient(135deg,#0f766e,#2563eb)]` electric gradient on ResultVisual card

```css

  scroll-snap-align: start;
```

**Effect**: All direct children of `<main>` (Hero, TrustStrip, HowItWorks, WebExperience, Faq, SupportSection, IndependenceNotice) now snap to viewport start with proper offset for fixed navigation.

- **Replaced**: `bg-[linear-gradient(135deg,#0f766e,#2563eb)]` → `bg-teal` (solid color)
- **Shadow**: `shadow-[0_12px_30px_rgba(15,118,110,0.2)]` → `shadow-[0_8px_20px_rgba(15,118,110,0.18)]` (softer)

**Visual Impact**: Cleaner, more sober appearance consistent with design system. No visual noise from blur or electric gradients.

### 3. HeroPreview i18n - `src/components/HeroPreview.tsx`
- **Before**: `// DEMO VISUAL · EJEMPLO ILUSTRATIVO` (hardcoded Spanish)
